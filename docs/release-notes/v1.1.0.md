## What's changed

- Added recipe templates — save recipes with ingredient notes and quick-fill new entries from a recipe dropdown
- Added sync with self-hosted server — synchronize your data over LAN with a Go sync server
- Added reminders — configure daily notifications per meal (Breakfast, Lunch, Dinner) via WorkManager
- Added Cooking Calendar — monthly calendar view with daily cooking plans, recipe dropdown, and full sync support
- Added hamburger drawer with Today, Timeline, Recipes, Reminders, Cooking Calendar, and Settings
- Added Settings screen with server URL, sync button, and last sync time
- Container images now published to GitHub Container Registry on every release
- All IDs changed from auto-increment to UUIDv7 for cross-device uniqueness
- Soft deletes replace hard deletes for proper sync conflict resolution
